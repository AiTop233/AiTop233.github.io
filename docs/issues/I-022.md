## 目标

- 意图：别人的资源名一塌糊涂——`【更多资源加群xxx】某某剧.1080p.全集.无删减.mp4`，直接分享出去很难看，也不统一（现状）；不做则每个资源都要手工改名，或带着别人的广告一起分发（代价）
- 行为：套一个模板 → 网盘上的文件夹名与文件名按模板生成、广告词被清掉、多余层级拍平；**文件本身一个字节都不动**
- 机制：`transforms/name.py`（模板渲染 + `strip` 正则清洗 + 前后缀）、`transforms/structure.py`（层级拍平）；`order` 决定执行顺序；渲染结果统一过 `clean_title()` 的非法字符规则

## 边界

- **只改名字**，不改内容：`name` / `structure` 都是字符串变换，不下载、不转码
- 不做媒体加工（去片头、贴片、转码）——那是 I-023，成本差一个数量级
- 不做智能识别（从文件名猜剧名/季集），只做模板与规则；猜错比不做更糟
- 拍平只处理「同名重复层」，不做任意层级重排

## 风险与对策

- **改名撞车**：服务端改名失败或覆盖都危险 → 先查目录，重名加后缀
- **模板把名字改坏**：默认模板只做「标题 + 季集」，不做花哨拼接；预览必须能看（渲染结果先给人确认一次）
- **与原资源脱钩**：改名后无法再用原文件名对照 → 台账保留 `source_ref` 与原名

## 过程记录

- 分层理由：`name` 零成本可组合，`media` 重成本且破秒传，必须分开排期（`SOURCES.md` §5）
