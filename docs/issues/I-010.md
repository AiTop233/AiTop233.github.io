## 目标

- 意图：想在页面上一眼看到三个网盘/文档通道是否就绪、配置随手改（目标）；现在要跑命令、手改 config.toml（现状）；不做则出问题时排查还要回终端（代价）
- 行为：状态灯显示百度 / 夸克 / 飞书登录态（失效时附「怎么办」指引与 secrets 缺失提示）；设置页编辑默认目录、飞书 doc_token、监控参数并保存生效；凭据文件状态（哪些 secrets 文件在 / 缺）
- 机制：`GET /api/status`（驱动 auth_check + writer auth_check）、`GET/PUT /api/config`（白名单字段写入 config.toml）；secrets 只报存在性，永不上传内容（AC-04）
