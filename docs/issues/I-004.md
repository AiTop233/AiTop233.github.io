## 目标

- 意图：想一条命令完成「上传 + 拿链接」（目标）；现在驱动有了但要手工串步骤、没有去重与记录（现状）；不做则每次上传都要多步操作且容易重复传（代价）
- 行为：一条命令上传到指定网盘指定目录，输出链接与提取码；同一文件重复上传时提示去重并返回已有链接，`--force` 可强制重传；失败时退出码非 0 并输出恢复指引；`status` 子命令可查最近上传记录
- 机制：`core/pipeline.py` 编排去重检查 → mkdir → upload → share → writer → 台账；`core/ledger.py` SQLite 台账；`cli.py` 用 `argparse` 暴露 upload / status 子命令
