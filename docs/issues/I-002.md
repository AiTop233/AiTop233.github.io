## 目标

- 意图：想把文件程序化地传进百度网盘指定目录并拿到分享链接（目标）；现在百度没有程序化通道，只能手动在网页上传、手动分享（现状）；不做则 F1 / F2 对百度不可用，文件还得手动传（代价）
- 行为：登录态可校验；建目录幂等；上传成功（秒传命中时跳过字节上传）；分享返回链接与提取码；cookie 失效时报错并给出恢复指引
- 机制：移植本人已验证的网页版接口实现到 `drivers/baidu.py`（precreate → 分片上传 → create → 分享接口），对齐 Driver 基类契约；errno 中文对照表随驱动沿用
