## 目标

- 意图：想把文件程序化地传进百度网盘指定目录并拿到分享链接（目标）；现在百度没有程序化通道，只能手动在网页上传、手动分享（现状）；不做则 F1 / F2 对百度不可用，文件还得手动传（代价）
- 行为：登录态可校验；建目录幂等；上传成功（秒传命中时跳过字节上传）；分享返回链接与提取码；cookie 失效时报错并给出恢复指引
- 机制：移植本人已验证的网页版接口实现到 `drivers/baidu.py`（precreate → 分片上传 → create → 分享接口），对齐 Driver 基类契约；errno 中文对照表随驱动沿用

## 过程记录

- 背景（规划期）：官方开放平台的分享 / 上传接口需企业认证主体，个人申请不下来；网页版接口（cookie 登录态）无此限制，且已实测可用（2026-11）。端点清单见模块 docstring。
- 目标：错误契约统一 ProjectError。现状：初版 `_json` 把 retriable 当构造参数传入，ProjectError 不收该参数，测试报 TypeError。答案：retriable 保持类属性默认 False，`_json` 按 errno 在实例上覆盖（`e.retriable = errno in RETRY_ERRNOS`）。
- 目标：桩测试覆盖 publish 全链路。现状：漏了 locateupload（上传节点）端点导致 5 例失败；顺序断言对同名端点（/api/create 出现两次）误报。答案：桩补 locateupload（注意它在 params 而非 URL）；顺序断言改为从上次命中位置之后查找。
- 目标：文件颗粒度。现状：baidu.py 568 行，超过 ~500 行软哨兵。答案：审视后判定单职责（同一上游 API 的契约方法 + 错误表 + 传输层），不拆；将来加转存 / 直链等功能时按职责再拆。
