## 目标

- 意图：想要一个配置与密钥有固定去处、错误与日志格式统一的项目底座（目标）；现在目录里没有任何代码（现状）；不做则后续每个模块各自造配置读取与报错格式，凭据散落有泄露风险（代价）
- 行为：配置从文件与环境变量加载，缺必需项时一次性报出全部缺失清单；日志按 JSON lines 落盘；错误类型统一携带错误码与恢复指引
- 机制：`config.py` 用 `tomllib` 读配置、环境变量覆盖；`core/errors.py` 定义 `ProjectError` 族；`core/log.py` 写 JSON lines
