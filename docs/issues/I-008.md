## 目标

- 意图：想拖个文件进浏览器就完成上传拿链接、历史记录随时可查（目标）；现在只能敲命令、记录要看终端（现状）；不做则「难管理」的核心痛点不解决（代价）
- 行为：上传页拖拽/选文件 → 选网盘 + 目录 + 日期开关（+可选写入飞书）→ 显示链接与提取码（可复制）；记录页列出台账（时间 / 网盘 / 远端路径 / 链接 / 提取码 / 失败原因），链接可点击，失败项一键重传；错误顶部提示条带「怎么办」
- 机制：`POST /api/upload`（multipart 流式转发给管道）、`GET /api/uploads`、`POST /api/uploads/{id}/retry`；前端 state 整体刷新
