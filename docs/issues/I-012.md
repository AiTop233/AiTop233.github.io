## 目标

- 意图：想让工具写进文档的内容和我手写的版式一模一样（目标）；现在追加「时间 · 文件名 · 链接（提取码）」到末尾，与我「YYMMDD 主题标题插最顶 + 盘名：链接」的版式冲突（现状）；不做则自动化越勤文档越乱、还要手工整理（代价）
- 行为：每次成功上传，向文档最顶（第一个标题块前；无标题块则最前）插入一个小节：h2 标题「YYMMDD 文件名（不带扩展名）」+ 每盘一行「盘名：链接?pwd=提取码」（全角冒号；提取码内嵌进链接；链接可点击）；无「（提取码 x）」后缀、无时分
- 机制：`feishu.append_record` 先列页面块找插入 index（首个 block_type 3–11 标题块的位置；找不到用 0），POST children 的 body 带 index；盘名映射 quark→夸克、baidu→百度、未知盘用原名；版式规则源头 = D-003 / PRD F3
