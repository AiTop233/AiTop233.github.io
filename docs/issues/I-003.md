## 目标

- 意图：想把文件程序化地传进夸克网盘指定目录并拿到分享链接（目标）；现在夸克只能手动上传分享（现状）；不做则 F1 / F2 对夸克不可用（代价）
- 行为：登录态可校验；上传成功（含大文件分片）；分享返回链接与提取码；cookie 失效时报错并给出恢复指引
- 机制：参考 alist 夸克驱动的接口流程自建 `drivers/quark.py`（登录态 cookie、预上传 → 分片 → 落盘 → 分享接口），风格与契约对齐 `drivers/baidu.py`
