## 目标

- 意图：把整个资源文件夹拖进浏览器就能传，网盘上结构与本地一致（目标）；现在拖文件夹**静默无反应**（`<input type="file">` 没开目录模式、drop 只取 `files[0]`，文件夹进不来）（现状）；不做则「资源包」只能先在资源管理器里拆开一个个传，等于没落地 D-005 的 Web 入口（代价）
- 行为：拖入文件夹递归读取并保留相对路径；也支持一次多选文件；结果卡片显示资源文件夹链接、已传文件数、失败的盘；记录页显示 `kind` 与文件数；重传沿用原资源文件夹
- 机制：前端 drop 用 `webkitGetAsEntry()` 递归（兼容 `<input webkitdirectory>` 兜底）；`POST /api/upload` 改 `files`（多值）+ `paths`（相对路径，一一对应）；服务端在 `data/inbox/<任务>/` 下按 `paths` 还原目录结构再交 `publish_task`；`retry` 用资源文件夹的父目录作 `remote_dir`、沿用原 `title`
