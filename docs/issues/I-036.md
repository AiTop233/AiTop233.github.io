# I-036 · 飞书多维表格替代文档，便于搜索与检索

> 类型：feature · 需求：后续阶段，需求修订待规划 · 关联：I-005、I-012、I-015、I-035 · 预期触达：writers / core / config · 验收标准冻结：未冻结（草稿，待确认）

## 目标（草稿）

- 意图：方便用户搜索和检索资源；当前飞书文档按小节追加资源，缺少结构化字段；不改则资源增多后查找和筛选不便。
- 行为：后续资源更新写入飞书多维表格，替代当前飞书文档；用户能通过资源名称搜索、按约定字段筛选并取得分享链接。
- 机制：增加飞书多维表格写入能力；字段、记录粒度、去重与更新规则，以及旧文档数据迁移范围待规划确认。

## 用户原话

「增加一个issue——飞书文档要换成多维表格，这样便于用户搜索和检索」
