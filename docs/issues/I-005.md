## 目标

- 意图：想上传完成后的链接自动出现在我的飞书文档里（目标）；现在要手动复制粘贴链接，记录散在各处找不回（现状）；不做则分享记录无法沉淀，回查要翻聊天记录（代价）
- 行为：配置指定目标飞书文档；每次成功上传后向该文档追加一行「时间 · 文件名 · 链接（提取码）」，链接可点击；凭证失效或文档无权限时报错含恢复指引，且不阻塞上传本身
- 机制：`writers/feishu.py` 直调飞书开放平台 docx API（tenant_access_token 获取并缓存、向文档追加文本块、text_run 设置 link 样式）；注册进 core 的 writer 注册表，I-004 的 `--doc feishu` 接线生效
