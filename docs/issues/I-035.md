# I-035 · 接入腾讯文档，与飞书同步更新

> 类型：feature · 需求：后续阶段，正式需求编号待规划 · 关联：I-005、I-015 · 预期触达：writers / core · 验收标准冻结：未冻结（草稿，待确认）

## 目标（草稿）

- 意图：同一次资源更新同时记入腾讯文档与飞书；当前仅接入飞书；不做则需要手工同步腾讯文档，两处记录可能不一致。
- 行为：配置两个文档目标后，一次资源更新在腾讯文档和飞书中均能看到对应资源及分享链接。
- 机制：通过 writers 扩展腾讯文档写入端，复用任务聚合；接入权限、失败处理与重试规则待规划确认。
