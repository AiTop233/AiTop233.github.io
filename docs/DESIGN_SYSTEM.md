# 设计系统：网盘自动上传

> 数值的唯一真源是代码里的语义变量：`src/panup/web/static/styles.css` 的 `--*`。
> 本文件只写约定与指向，不抄数值。

## 1. 取用顺序

本项目约定 > 《前端设计规范》；冲突且造成实际问题时，按 `AGENTS.md` 第 3 节判档，不擅自改。

## 2. 界面结构

- 页面 / 导航：单页四区块——上传（默认）/ 记录 / 监控 / 设置，顶部标签切换；无路由跳转
- 主流程：上传 = 拖入文件**或整个文件夹**（也可点击多选）→ 勾选网盘（可多选）并为每个盘设目录 + 填标题（可留空）+ 日期开关 → 上传 → 结果卡片（各盘**资源文件夹**链接可点击复制）；记录 = 进页拉取台账表，失败项集中在「待修」
- 操作触发什么：上传按钮 → `POST /api/upload` → 结果追加到当前列表并刷新记录页；规则操作 → 卡片即时消失/出现
- 空 / 加载 / 错误：空态写明「暂无记录 / 还没有监控规则，去监控根目录建 `网盘@远端目录` 文件夹」；加载用按钮内联「…」；错误顶部提示条（红），带 hint
- 每屏的块序与主次：以各 issue 的「界面结构骨架」为准；本节只记页面级组织

## 3. 色

- 主题色：中性深灰蓝（管理台气质，不绑定任一网盘品牌色）；提醒色 = 危险红（另一支）
- 语义色：成功绿 / 危险红 / 说明灰（状态灯：百度 / 夸克 / 飞书三灯复用成功与危险）
- 中性底与文字、描边：白底深字浅描边（按《前端设计规范》默认灰阶）
- 明暗两套：无（个人管理台，不做暗色切换）
- 对比度：手工核对状态灯与提示条文字对白底

## 4. 字与尺寸

- 字号刻度：正文 / 辅助 / 标题三档；最小档给表格辅助列
- 行高、字重、间距刻度、圆角刻度（卡片与按钮小圆角）、断点：无响应式断点（桌面浏览器固定宽度使用）

## 5. 组件

- 自己写：状态灯、拖拽区、规则卡片、提示条、表格
- 用库：无（原生 HTML/CSS/JS，无组件库）
- 本项目不许的用法：不引入组件库 / 构建链 / CSS 框架（与 FRONTEND.md §7 一致）

## 6. 视觉语言

- 《前端设计规范》选「克制工具风」一套：信息密度优先、装饰最少、动效仅按钮与提示条过渡
- 八维取值：低阴影、小圆角、无渐变、左对齐为主、数字等宽（链接列）
