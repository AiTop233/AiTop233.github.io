# PRD：网盘自动上传

## 一句话

把本地文件**或文件夹**自动传到百度/夸克网盘的指定目录，拿到分享链接并自动记进飞书文档的个人工具。

## 给谁

只有本人使用：单机、各网盘用本人自己的账号，无多用户与权限设计（多用户见「后续阶段」）。

## 做（阶段 1）

| 编号 | 需求 | 说明 |
|---|---|---|
| F1 | 手动上传 | 一条命令把**一个资源**（单个文件，或一个文件夹）上传到**一个或多个网盘**，每个网盘各自指定目录；网盘上落为一个以**标题命名**的资源文件夹（单文件也建文件夹），文件夹内部的子目录原样保留；分享链接指向该文件夹，返回各盘链接与提取码 |
| F2 | 监控自动上传 | 监控指定的本地文件夹，新文件出现后自动按规则上传到对应网盘目录；每个文件同样落为一个资源文件夹，名字用文件名（去扩展名） |
| F3 | 链接写入飞书文档 | **一次上传任务**（可能含多个网盘）成功后，向指定飞书文档**最顶**插入一个小节：h2 标题「YYMMDD 标题名」（标题由人指定，未指定用文件名/文件夹名）+ 每个**成功**网盘一行「盘名：链接?pwd=提取码」（提取码内嵌进链接，**链接指向该盘的资源文件夹**），链接可点击，最新在最前；本次失败的网盘不写进小节，留在待修列表 |

## 做（阶段 2 · 本地管理台）

| 编号 | 需求 | 说明 |
|---|---|---|
| F4 | 本地网页管理台 | `panup serve` 起本地服务（只监听本机回环地址），浏览器完成：手动上传（拖拽**文件或整个文件夹**、一次可多选、**网盘多选**与每盘目录、标题）、上传记录仪表盘（含**失败待修列表**与重试）、监控规则管理、登录态与配置 |
| F5 | 目录约定自动化 | 监控根目录下按「`网盘@远端目录`」命名的子文件夹自动成为监控规则（远端多级目录用 `__` 分隔）；文件夹里的文件一律追加「年/月/日」子目录，再按 F2 落为资源文件夹上传并自动记录，文件名不编码、原样上传 |

每条需求的边界与异常：

**资源文件夹规则（F1 / F2 / F4 / F5 共用）**：一次上传 = 一个资源 = 网盘上的一个文件夹，路径为「基础目录 / [年/月/日/] 标题 / 内容」。

- 文件夹名即标题；标题里的 `/ \ : * ? " < > |` 与控制字符替换为 `_`，首尾空格和点去掉；替换后为空则报错，要求给一个可用标题
- 单文件也建这个文件夹，里面就一个文件；上传文件夹时本地子目录原样保留，空目录跳过
- 标题由人指定（CLI `--title` / 页面输入框），未指定时用文件名或文件夹名（去扩展名）
- **网盘上已有同名文件夹 → 报错并提示换标题**，不合并、不覆盖（重传走待修流程，不会新建文件夹）
- 分享链接指向该资源文件夹，一条链接覆盖整个资源

- **F1**：一个资源可同时传多个网盘，各盘各自一个远端目录（缺省用该盘的默认目录）；某个盘失败不影响其他盘继续，失败项留在台账「待修」，飞书小节只写成功的盘；分享默认永久 + 随机提取码。
- **F2**：监控触发的每个新文件自成一个资源（资源文件夹名 = 文件名去扩展名）；同一文件（同路径、同大小、同修改时间）不重复上传。
- **F3**：一次上传任务只出一节，节内按盘排行，行序固定（百度 → 夸克 → 后续新盘按注册顺序）；人工重传失败盘时补写新行还是并入原节，由待修流程决定（见 F4）。
- **F4**：服务只监听 127.0.0.1，不对局域网开放；上传走浏览器表单——拖入**文件夹会被递归读取并保留相对路径**，也可一次多选文件；多文件逐个流式转发，不打包成压缩包，不支持断点续传（中断即整任务失败、可从待修重传）；网盘可多选，每个勾选的盘可单独设目录；watch 的启停在页面里操作，服务重启后规则仍在。失败时的表现：任何接口错误在页面显示「发生了什么 + 怎么办」（与 CLI 同一套错误文案）；失败的上传进「待修」列表，可单条重试；登录态失效显示体检红灯与恢复指引。
- **F5**：文件夹名不符合约定（没有 `@` 或网盘名不是 baidu/quark）→ 忽略该文件夹并在页面「监控」区显示「未识别」；文件夹重命名 = 规则即时变更，删除文件夹 = 停止该规则；文件夹里的子目录同样递归监控；文件名不编码（不携带指令），分享默认永久。数据的可见范围与阶段 1 相同（分享链接 + 提取码；台账与日志仅本机）。

## 成功标准

- F1：一条命令完成上传并输出可打开的分享链接；一条命令同时传两个盘时，两盘各自出链接且都能打开；本人抽验 3 个文件，链接全部可下载；再传一个含两级子目录的文件夹，两盘上的目录结构与本地一致，一条链接能浏览全部内容，飞书该节只有一行链接
- F2：监控运行期间放入 5 个文件，5 个全部出现在网盘目标目录（各自一个资源文件夹）；重启监控后同一文件不重复上传
- F3：连续上传 10 个文件，飞书文档最顶出现 10 个新小节且最新在最前，链接可点击且指向资源文件夹；一个文件传两个盘时只出现**一个小节、两行链接**，不出现两节
- F4：在浏览器里 3 次操作内完成一次上传并拿到链接；台账页能看到全部历史记录，失败项集中列在「待修」里并可一键重传
- F5：在监控根下新建一个约定文件夹放入 3 个文件，不做任何其他配置，文件自动出现在约定网盘目录并进台账
- 自己连续使用 2 周不弃用

## 待确认

- 监控是否递归子目录（暂定递归）
- 文件稳定判定等待时长（暂定 10 秒）
- 分享链接默认有效期与提取码（暂定永久 + 随机 4 位）
- 同名文件覆盖策略：**已定（D-005）**——不再按文件覆盖，网盘上同名资源文件夹一律报错、不合并
- 大文件夹（几百个文件 / 多 GB）的 Web 上传进度与并发（暂定：逐个串行，无进度条，先跑通）
