# PRD：网盘自动上传

## 一句话

把本地文件自动传到百度/夸克网盘的指定目录，拿到分享链接并自动记进飞书文档的个人工具。

## 给谁

只有本人使用：单机、各网盘用本人自己的账号，无多用户与权限设计（多用户见「后续阶段」）。

## 做（阶段 1）

| 编号 | 需求 | 说明 |
|---|---|---|
| F1 | 手动上传 | 一条命令把指定文件上传到指定网盘的指定目录，返回分享链接与提取码 |
| F2 | 监控自动上传 | 监控指定的本地文件夹，新文件出现后自动按规则上传到对应网盘目录 |
| F3 | 链接写入飞书文档 | 每次上传成功后，向指定飞书文档追加一行「时间 · 文件名 · 链接（提取码）」，链接可点击 |

每条需求的边界与异常：

- **F1**：一次指定一个文件或一个目录（目录按逐个文件处理）；同名文件默认覆盖；不支持断点续传，中断后重传整个文件。失败时的表现：网盘 cookie 失效 → 报错并提示重新导出 cookie；空间不足、文件被占用 → 报错、退出码非 0，本地台账记失败，不静默丢。
- **F2**：监控目录与「网盘 + 目标目录」的映射写在配置里；文件写入完成（大小稳定）后才上传；同一文件不重复上传，重启监控后依然不重复。失败重试上限 3 次，仍失败记入台账（failed）并保留恢复指引；连续失败达到上限停止监控并醒目提示。
- **F3**：只向配置指定的那篇已存在文档追加，需要本人把该文档授权给飞书应用（一次性）；凭证失效、文档无权限、接口限频 → 报错含恢复指引。写入失败不阻塞上传本身（链接已记入本地台账）。数据的可见范围：分享链接的可见性由网盘分享机制决定（链接 + 提取码）；本地台账与日志只存在本人机器。

## 后续阶段（只列标题，当前不做、不设计）

## 不做（当前场景外，进入需重新评估）

- 网盘文件管理全家桶：跨盘互转、批量重命名、去重整理、转存他人分享
- WebDAV、挂载为本地磁盘
- 云下载（磁力 / BT / 直链）
- 商业分发与自动更新机制（本机自用工具）

## 成功标准

- F1：一条命令完成上传并输出可打开的分享链接；本人抽验 3 个文件，链接全部可下载
- F2：监控运行期间放入 5 个文件，5 个全部出现在网盘目标目录；重启监控后同一文件不重复上传
- F3：连续上传 10 个文件，飞书文档末尾出现 10 行且链接可点击
- 自己连续使用 2 周不弃用
